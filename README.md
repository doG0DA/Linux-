Этап 1. REPL

Консольный прототип оболочки. Приглашение к вводу собирается из данных ОС (имя пользователя, имя компьютера, текущая папка). Переменные окружения вида $HOME и ${HOME} раскрываются. Команды ls и cd пока заглушки и выводят своё имя и аргументы, exit завершает работу. На неизвестную команду и неверные аргументы выводится ошибка.

Запуск
javac -d out src/*.java
java -cp out Main

Или запустить класс Main в IntelliJ IDEA.

Пример
yura@laptop:~$ ls -l $HOME
ls [-l, /home/yura]
yura@laptop:~$ cd a b
cd: слишком много аргументов
yura@laptop:~$ foo
foo: команда не найдена
yura@laptop:~$ exit
